Blender add-ons for hard-surface modelling and game asset pipelines.

I write tools for the boring parts of 3D work — the panelling, the renaming, the export checks. Everything here is tested against Blender 3.6 LTS, 4.2 LTS, 4.5 LTS, 5.0 and 5.2 before it goes out, because add-ons that quietly break on a version bump are the main reason people stop trusting them.

PanelForge

Procedural sci-fi hull plating. It takes a hard-surface mesh and generates panel layouts, recessed sections, slatted vents, raised blocks and blade fins, assigned across five material slots.

The detail is placed rather than sprayed. Plate depths step in fixed increments instead of drifting, detail clusters into hotspots the way real hardware does, and some plating is deliberately left off so bare hull shows through. Sixteen parameters, one seed, reproducible output.

In development. Coming to Superhive.

On testing

Every add-on here is installed, enabled, run against real geometry and unloaded again, automatically, on five Blender versions. That is 60 combinations per release. It is more effort than a free tool strictly warrants, but it is the only way I know to honestly claim a version range.

It catches real things. The turntable tool worked fine on 3.6 and 4.2 and threw on 5.x, because Action.fcurves stopped existing when Blender restructured Actions into layers and slots in 4.4. Without the matrix I would have shipped that and only found out from a bug report.
